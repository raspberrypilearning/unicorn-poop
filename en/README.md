# Unicorn poop project structure

This project is an HTML project for the Raspberry Pi Code Editor.

```plaintext
en/
├── code/
│   ├── unicorn-poop-complete/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── project_config.yml
│   └── unicorn-poop-starter/
│       ├── index.html
│       ├── style.css
│       └── project_config.yml
├── images/
│   ├── .keep
│   └── banner.png
├── resources/
│   └── .keep
├── solutions/
│   └── .keep
├── landing.md
├── meta.yml
├── step_1.md
├── step_2.md
├── step_3.md
├── step_4.md
└── step_5.md
```

The starter folder contains the minimal files learners begin with. The complete folder contains the finished poster shown on the landing page.
